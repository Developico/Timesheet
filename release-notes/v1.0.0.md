## Funkcjonalności / Features

### Kalendarz / Calendar
- Widok miesięczny z nawigacją miesiąc/rok
- Dodawanie, edycja, usuwanie wpisów czasu pracy
- Wizualna prezentacja godzin (kolor projektu, pasek postępu)
- Obsługa dni wolnych i świąt

### Dashboard
- Podsumowanie godzin (tydzień / miesiąc)
- Rozkład czasu wg projektów (wykres kołowy)
- Trend dzienny (wykres liniowy)
- Top projekty i ostatnie wpisy

### Projekty / Projects
- Lista projektów z wyszukiwaniem i filtrowaniem
- Szczegóły projektu: budżet godzinowy, daty, status
- Przypisywanie użytkowników z rolami (member / manager)
- Kolorowe etykiety projektów

### Raporty / Reports
- Raporty godzinowe wg projektów i użytkowników
- Filtry: zakres dat, projekt, osoba
- Widok tabelaryczny i wykresowy

### Panel administracyjny / Admin Panel
- Zarządzanie projektami (CRUD)
- Zarządzanie użytkownikami
- Konfiguracja systemowa
- Diagnostyka połączenia z Dataverse

### Uwierzytelnianie / Authentication
- Microsoft Entra ID (Azure AD) via NextAuth.js
- RBAC: grupy TT-Administrators / TT-Consultants
- Middleware autoryzacyjne na poziomie tras
- Obsługa JWT i odświeżanie tokenów

## Źródła danych / Data Sources
- Adapter Dataverse (OData v4.0) — produkcyjne
- Adapter Mock — do developmentu i testów
- Wzorzec Factory z interfejsem `IDataSource`
- Przełączanie via `DATA_SOURCE=mock|dataverse`

### Power Platform
- Dataverse solution: schemat tabel tt_*, widoki, security roles
- Custom Connector: integracja Power Automate / Canvas App z web API
- Canvas App: mobilna rejestracja czasu pracy
- Model-Driven App: panel administracyjny

### Skrypty wdrożeniowe / Deployment Scripts
- PowerShell: Install-Timesheet.ps1, Setup-EntraId.ps1, helpers/Common.ps1
- Provisioning: Provision-FullEnvironment.ps1
- Root: start-timesheet.cmd, stop-timesheet.cmd
- Dokumentacja publiczna: README (PL/EN), SECURITY, CONTRIBUTING, CODE_OF_CONDUCT, LICENSE

## Infrastruktura / Infrastructure

- **Framework**: Next.js 14.2 (App Router + Pages Router)
- **Runtime**: Node.js 20 LTS
- **Hosting**: Azure App Service (Linux, standalone build)
- **CI/CD**: GitHub Actions (typecheck → test → build → deploy)
- **Testing**: Vitest (unit/integration), Playwright (E2E)
